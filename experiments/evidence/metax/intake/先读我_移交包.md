分发日期：2026-11-23。本包用于阅读知识库、复用实验代码和审计历史结果。**本包不是完整离线安装包，也不是已在新服务器验证的一键部署套件。**

## 接收后先做什么

1. 核对压缩包旁的 `.sha256`，解压到独立目录，保留压缩包作为原始交付版本。
2. 在解压后的项目根目录，用 Python 3.10+ 执行 `python -B verify_package.py`，确认文件清单、大小和 SHA256 全部一致。清单自身不自哈希，由压缩包的外部 SHA256 覆盖。
3. 阅读[移交说明](移交说明_C500_GLM模型复现.md)，重点是第5—6节与第12节的材料、路径和无镜像重建要求；让协作 Agent 阅读 [AGENTS.md](received-agents.md)。
4. 需要查资料时，从 [hwdoc/README.md](../../../../catalog/library/metax/hwdoc/README.md) 和[实践入口](../../../../catalog/library/metax/hwdoc/practice/README.md)开始。例如 `python -B hwdoc/tools/search.py weight_scale --source practice --limit 5`。
5. 复制一份工作目录后开展迁移；历史证据、协议和 manifest 保留原样。新服务器使用新的运行目录、环境指纹、同期基线和结果清单。

Windows 示例中的 Python 绝对路径属于原作者机器；接收方应改为自己的 Python。核验时使用 `-B` 避免生成缓存。脚本、容器名、镜像、远程路径和设备配置须按移交说明核对，不能直接照搬。
