atomicCAS函数读取global或者shared内存 （address） 的原始数据 （old） ， 计算算式 “old==compare
? val : old”后将结果写入 address 地址中，并返回 old 数据。该函数保证对应的（system，device，
block中的一种）原子性。

unsigned int atomicAnd(unsigned int* address, unsigned int val);

atomicAnd函数读取global或者shared内存（address）的原始数据（old） ，计算算式“old&val”后
将结果写入address地址中，并返回old数据。该函数保证对应的（system，device，block中的一种）
原子性。
2.14.2.2 atomicOr()
int atomicOr(int* address, int val);

unsigned long long int atomicOr(unsigned long long int* address,
unsigned long long int val);

将结果写入address地址中，并返回old数据。该函数保证对应的（system，device，block中的一种）
原子性。
