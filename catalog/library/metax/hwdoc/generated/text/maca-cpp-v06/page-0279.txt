MXMACA® C++ 编程指南
参数名 说明
global_addr 全局内存地址
offset 全局内存偏移
data 待写入数据（位宽与内置函数名一致）
saddr_flag 选择使用 sreg作为地址
pred_neg 反转比较结果生成的活跃掩码
is_async 异步加载，需在后续手动进行同步
cmp_op1 比较指令的第一个操作数
cmp_op2 比较指令的第二个操作数
cmp_flag 比较方式，可取值为 MACA_ICMP_EQ | NE | UGT | UGE | ULT | ULE |
SGT | SGE | SLT | SLE，与 cmp_op1和 cmp_op2共同决定 predicator
示例
__global__ void test_builtin_mxc_stg_b32_predicator(void *ptr,
unsigned val,
int a, int b)
{
__builtin_mxc_stg_b32_predicator(ptr,
0, // offset
val,
false, // saddr_flag
false, // pred_neg
false, // is_async
a, b, // cmp_op1, cmp_op2
MACA_ICMP_EQ);
}
