mxvs 测试工具套件使用手册
10 算力测试工具
10.1 算力测试
命令
/opt/maca/bin/mxvs ops --devices <DEVICE_ID> --models <MODEL_NAME>
命令参数
表 10.1 算力测试命令参数
参数 必填 描述
-m, --models 否 测试对象精度， 可指定精度： bf8、 fp8、 int8、 bf16、 fp16_matrix、
fp16_vector、 fp32_matrix、 fp32_vector、 tf32 等，不同系列支
持的精度类型不一样，无后缀默认为 matrix。若不指定该参数，
默认测试所有支持的精度。
-d, --devices 否 测试对象 PCIe 设备编号，支持单个设备测试或多个设备同时测
试。如果需要指定所有设备，可用 all 作为参数值，默认选择所
有 PCIe 显卡设备。 若为 sGPU 场景， 则需传入--detail 和具体
的 sGPU 设备编号，如 -d 0-s0 ，即被测对象为设备 0 上的子设
备 0。
--mode 否 指定算力测试模式：
0：全 0 矩阵（默认）
1：随机值 sin/cos
2：随机值
--bref 否 仅显示测试结果，不显示 MetaX GPU 基本信息。
--json 否 将结果以 JSON 格式输出到文本中，可指定输出的文件名，如
--json result.json
--monitor-log 否 在测试期间若有内核错误可打印显示。
--detail 否 显示详细 GPU 测试结果，默认仅显示整板测试结果。
--blas 否 指定使用 gemm 执行算力测试。
-i, --iteration 否 用于指定算力测试遍历次数， 默认 10000 次。 若指定--blas， 则
默认为 100 次。
--matrix-size 否 用于指定算力测试矩阵 m、 n、 k 大小， 当前不支持vector 类型。
--validate 否 用 CPU 计算结果做校验，当前不支持 vector 类型结果校验；不
能与 --blas 一同使用。
