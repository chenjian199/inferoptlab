8.3.1.2 安装 wheel 包
操作步骤
1. 预先安装沐曦平台的 torch、flash attn、mcoplib、xformer（可选）环境。
2. 获 取MacaRT‑vLLM 压 缩 包 maca‑vllm‑metax‑0.11.0‑py310‑xxx‑${OS_Version}.tar .xz并 解
压。
3. pip 安装以下 wheel 包：
• vllm_metax‑0.11.0+xxx.whl
• flash_attn+xxx.whl （适配 vLLM 新加速 whl 包）
• ray‑2.48.0‑cp310‑cp310_${OS_Version}.whl
• mcoplib‑0.1.0‑+macaxxx‑cp310‑cp310_${OS_Version}.whl
• vllm‑0.11.0‑cp310‑xxx_${OS_Version}.whl
4. vLLM‑metax、vLLM、mcoplib 安装后需要手动执行 mcoplib_init 命令。
除了上述 wheel 包，其他依赖环境可以通过外部镜像源进行安装。安装过程中有其他依赖，需要提前配
置好 Python 的 pip 源。
8.3.1.3 源代码构建教程
从沐曦开发者社区 中获取 vLLM 镜像并启动，参见《沐曦通用 GPU 用户指南》中“容器相关场景支持”
章节。
