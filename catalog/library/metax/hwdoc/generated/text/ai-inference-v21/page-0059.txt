6.3.4.3 Python 客户端部署
安装 ppl.llm.serving_*_amd64.deb 后， 可在/opt/maca‑ai/ppl.llm.serving/samples/samples/ppl_
server_client/python_client/路径下获取 Python 代码示例。工程文件目录如图 6.3 所示：
• llm_pb2.py：与服务端交互时 grpc 依赖的 proto 定义文件。
• llm_pb2_grpc.py：与服务端交互时 grpc 依赖的 proto 定义文件。
• client.py：Python 客户端示例脚本。
图 6.3 Python 客户端目录结构图
参考 client.py 示例代码，根据业务需求定制相应的 Python 客户端即可。
Python 客户端依赖 grpc，使用时需安装 grpcio、grpcio‑tools 两个依赖项。
pip install grpcio
pip install grpcio-tools
