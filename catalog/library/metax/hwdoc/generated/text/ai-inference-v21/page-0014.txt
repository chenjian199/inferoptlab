1.2 MacaRT 功能
MacaRT 包含了以下的功能和特性：
• MacaRT 提供了 C++ 和 Python 接口
• 支持多种模型数据类型，包括 float32、float16、int8、uint8 等
• 支持动态 Batch 推理
• 支持多线程调用和多进程调用
• 支持模型图优化、模型量化等特性
• MacaRT 工具链，包括 MacaConverter、MacaPrecision、MacaQuantizer
