DeepEP 多机通信内存注册环境变量配置说明
2 配置说明
mxshmem 支持两种内存注册方式：
• DMA‑BUF
• Peer Memory
客户可以通过环境变量 MXSHMEM_IB_DISABLE_DMABUF 手动指定内存注册方式：
表 2.1 MXSHMEM_IB_DISABLE_DMABUF 环境变量配置
环境变量配置 内存注册方式
MXSHMEM_IB_DISABLE_DMABUF=0 启用 DMA‑BUF
MXSHMEM_IB_DISABLE_DMABUF=1 禁用 DMA‑BUF，使用 Peer Memory
实际支持及默认使用哪种方式， 取决于 MXMACA SDK Release 版本、 Linux Kernel 版本和 MOFED 版本。
2.1 不同 MXMACA SDK Release 版本的支持情况
2.1.1 MXMACA SDK Release 版本＜ 3.8.3
• 仅支持 Peer Memory，不支持 DMA‑BUF。
• 当 Linux Kernel 版本 ≥ 6.8 时，由于操作系统内核仅支持 DMA‑BUF 方式，DeepEP Low Latency 场
景将无法正常运行。
2.1.2 3.8.3 ≤ MXMACA SDK Release 版本 ≤ 3.10.0
该版本范围内，mxshmem 同时支持 DMA‑BUF 和 Peer Memory，默认使用 DMA‑BUF。客户也可以通
过环境变量 MXSHMEM_IB_DISABLE_DMABUF=1 手动切换为 Peer Memory。
表 2.2 不同 MOFED 版本的内存注册方式
Linux Kernel 版本 MOFED 版本 默认内存注册方式 使用说明
≥ 5.16 不限 DMA‑BUF 默认使用 DMA‑BUF
＜ 5.16 以下指定版本 DMA‑BUF 默认使用 DMA‑BUF
＜ 5.16 其他版本 DMA‑BUF 不可用 需 设 置
MXSHMEM_IB_DISABLE_DMABUF=1，
使用 Peer Memory
