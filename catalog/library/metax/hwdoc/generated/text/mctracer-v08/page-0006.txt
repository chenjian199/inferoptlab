mcTracer使用手册
1 概述
本文描述了 MXMACA® 软件栈中 mcTracer 工具的使用方法。
mcTracer 主要抓取 MXMACA 应用程序的活动事件，并将活动事件按照时间序列进行展示。
mcTracer 分为两部分，分别是用于采集数据的采样端程序 mcTracer，以及用于显示活动序列的
mcTracer‑Viewer。
支持抓取的数据类型包括：
• MXMACA Runtime API，主要是 MXMACA 软件栈提供的 API 活动
• MXMACA Kernel，运行在沐曦通用 GPU 上的核函数
• MCTX，自定义标签段数据
1.1 适用产品
本文档适用于沐曦 MXC500 系列产品：曦云 ® C500、C500X、C550、C550‑PL、C588，曦思® N260，曦
索 ® X206；以及 MXC600 系列产品：曦云 ® C600，曦思 ® N300，曦索 ® X301、X302。
