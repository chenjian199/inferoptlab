mcPyTorch 用户指南
1 概述
mcPyTorch 在PyTorch的基础上增加了 MXMACA ® 后端，支持使用 MXMACA 硬件加速 PyTorch 中各类
计算任务。
当前发布包含以下版本安装包：
• PyTorch 2.4.0 + Python 3.8
• PyTorch 2.4.0 + Python 3.10
• PyTorch 2.4.0 + Python 3.12
• PyTorch 2.6.0 + Python 3.10
• PyTorch 2.6.0 + Python 3.12
• PyTorch 2.8.0 + Python 3.10
• PyTorch 2.8.0 + Python 3.12
• PyTorch 2.10.0 + Python 3.10
• PyTorch 2.10.0 + Python 3.12
支持 x86_64/Arm 架构下 Ubuntu 20/22/24 以及 CentOS 8/9 系统上运行。mcPyTorch 的具体支持功
能，参见 3 功能支持。
1.1 适用产品
本文档适用于沐曦 MXC500 系列产品：曦云 ® C500、C500X、C550、C550‑PL、C588，曦思® N260，曦
索 ® X206；以及 MXC600 系列产品：曦云 ® C600，曦思 ® N300，曦索 ® X301、X302。
