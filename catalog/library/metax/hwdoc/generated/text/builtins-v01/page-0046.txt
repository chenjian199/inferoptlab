3.8.6 __builtin_mxc_nop
功能描述
插入一定数量的空操作。
接口声明
int __builtin_mxc_nop(int n)
参数
表 3.31 __builtin_mxc_nop 参数说明
名字 描述
n 空操作数量。每个空操作等于 4 拍。
代码示例
__device__ void test_mxc_nop() {
__builtin_mxc_nop(32); // wait for 128 cycles
return;
}
