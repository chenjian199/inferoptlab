mcBLAS API 参考
返回值 含义
MCBLAS_STATUS_SUCCESS 操作成功
MCBLAS_STATUS_NOT_INITIALIZED 库未初始化
MCBLAS_STATUS_INVALID_VALUE • m, n < 0
• side != MCBLAS_SIDE_LEFT,
MCBLAS_SIDE_RIGHT
• uplo != MCBLAS_FILL_MODE_LOWER,
MCBLAS_FILL_MODE_UPPER
• 如 果 side == MCBLAS_SIDE_LEFT ，lda <
max(1, m) ；否则 lda < max(1, n)
• ldb < max(1, m)
• ldc < max(1, m)
• alpha == NULL 或 beta == NULL
• 如果 C 需要缩放，C = NULL
MCBLAS_STATUS_EXECUTION_FAILED 此函数在 GPU 上启用失败
