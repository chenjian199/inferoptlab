mcBLAS API 参考
返回值 含义
MCBLAS_STATUS_SUCCESS 操作成功
MCBLAS_STATUS_NOT_INITIALIZED 库未初始化
MCBLAS_STATUS_INVALID_VALUE
• m < 0 或 n < 0
• transa != MCBLAS_OP_N, MCBLAS_OP_C,
MCBLAS_OP_T
• transb != MCBLAS_OP_N, MCBLAS_OP_C,
MCBLAS_OP_T
• 如果 transa == MCBLAS_OP_N ，lda < max(1,
m) ；否则 lda < max(1, n)
• 如果 transb == MCBLAS_OP_N ，ldb < max(1,
m) ；否则 ldb < max(1, n)
• ldc < max(1, m)
• A == C, ((MCBLAS_OP_N != transa) || (lda != ldc))
• B == C, ((MCBLAS_OP_N != transb) || (ldb != ldc))
• alpha == NULL 或 beta == NULL
MCBLAS_STATUS_EXECUTION_FAILED 此函数在 GPU 上启用失败
