mcBLAS API 参考
返回值 含义
MCBLAS_STATUS_SUCCESS 操作成功
MCBLAS_STATUS_NOT_INITIALIZED 库未初始化
MCBLAS_STATUS_INVALID_VALUE • n, k < 0
• trans != MCBLAS_OP_N, MCBLAS_OP_C,
MCBLAS_OP_T
• uplo != MCBLAS_FILL_MODE_LOWER,
MCBLAS_FILL_MODE_UPPER
• 如果 trans == MCBLAS_OP_N ，lda < max(1,
n) ；否则 lda < max(1, k)
• 如果 trans == MCBLAS_OP_N ，ldb < max(1,
n) ；否则 lda < max(1, k)
• ldc < max(1, n)
• alpha == NULL 或 beta == NULL
• 如果 C 需要缩放，C = NULL
MCBLAS_STATUS_EXECUTION_FAILED 此函数在 GPU 上启用失败
