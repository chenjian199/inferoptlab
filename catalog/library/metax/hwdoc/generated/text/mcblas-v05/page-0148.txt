此 函 数 是 mcblas<t>gemmStridedBatched 的 扩 展， 执 行 一 批 矩 阵 的 矩 阵‑矩 阵 乘 法， 并 允
许 用 户 单 独 指 定 每 个 A、B、C 矩 阵 的 数 据 类 型， 计 算 精 度 和 要 运 行 的 GEMM 算 法。 与
mcblas<t>gemmStridedBatched 相似，该批是“均匀”的，即所有实例对于各自的 A、B、C 矩
阵具有相同的维度 （m，n，k） ，前导维度 （lda，ldb，ldc） 和转置 （transa，transb） 。 批处理中每个实
例的输入矩阵 A 和 B 以及输出矩阵 C 的位置，与前一个实例中的位置在元素数量上有固定的偏移。第一
个实例中指向矩阵 A、B、C 的指针，与元素数量的偏移量（strideA、strideB、strideC）一并由用户传
入函数，这些偏移量决定了后续实例中输入矩阵和输出矩阵的位置。
注解: mcblasGemmStridedBatchedEx 函数的第二个变量用于向后兼容 C++ 应用程序代码，其
中 computeType 参数是 macaDataType_t，而不是 mcblasComputeType_t。C 应用程序仍将
使用更新的函数签名进行编译。
