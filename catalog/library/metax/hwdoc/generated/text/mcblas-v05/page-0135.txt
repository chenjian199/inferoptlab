mcblasStatus_t mcblasZtrttp(mcblasHandle_t handle,
mcblasFillMode_t uplo,
int n,
const mcDoubleComplex *A,
int lda,
mcDoubleComplex *AP );
此函数执行从三角格式转换到三角压缩格式。
如果 uplo == MCBLAS_FILL_MODE_LOWER，则三角矩阵 A 的下三角部分将复制到 AP 数组中。如果
uplo == MCBLAS_FILL_MODE_UPPER，则三角矩阵 A 的上三角部分将复制到 AP 数组中。
参数 内存 In/out 含义
handle input mcBLAS 库上下文的句柄
uplo input 指示引用的是矩阵 A 的下半部分还是上半部分
n input 矩阵 A 的行数和列数
A 设备 input <type> 数组，维度为 lda x n ，其中 lda>=max(1,n) 。
lda input 用于存储矩阵 A 的二维数组的前导维度
AP 设备 output 以压缩格式存储 A 的 <type> 数组
下面列出了此函数可能的返回值及其含义。
返回值 含义
MCBLAS_STATUS_SUCCESS 操作成功
MCBLAS_STATUS_NOT_INITIALIZED 库未初始化
MCBLAS_STATUS_INVALID_VALUE • n < 0
• uplo != MCBLAS_FILL_MODE_UPPER,
MCBLAS_FILL_MODE_LOWER
• lda < max(1, n)
MCBLAS_STATUS_EXECUTION_FAILED 此函数在 GPU 上启用失败
