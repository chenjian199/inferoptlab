2.2 命令行参数
mx‑cmi 是通信库巡检工具，本功能（device_order）作为巡检工具中一个子功能，集成在 mx‑cmi 中。
在使用本工具前， 需要安装 MXMACA SDK， SDK 的安装目录可以自定义， 默认安装在/opt/maca。 如 SDK
安装在默认路径， 则 mx‑cmi 工具的具体路径为：/opt/maca/tools/communication/inspector/mx‑
cmi。
device_order 工具的具体使用参数如下：
usage: /opt/maca/tools/communication/inspector/mx-cmi device_order [-h] [--tp TP] 
,→[--dp DP] [--ep EP] [--pp PP] [--cp CP] [--visible-devices VISIBLE_DEVICES] [--
,→show-groups]
Generate MACA_VISIBLE_DEVICES ordering for METAX devices.
optional arguments:
-h, --help show this help message and exit
--tp TP tensor parallel rank num (default: 1)
--dp DP data parallel rank num (default: 1)
--ep EP expert parallel rank num (default: 1)
--pp PP pipeline parallel rank num (default: 1)
--cp CP context parallel rank num (default: 1)
--visible-devices VISIBLE_DEVICES, --visible VISIBLE_DEVICES
a list of visible devices, for example --visible 0,1,2,3,4,
,→5,6,7
--show-groups Print the per-dimension split summary.
