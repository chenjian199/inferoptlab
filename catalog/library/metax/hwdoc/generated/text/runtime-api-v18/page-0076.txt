图 4.8 printf 输出结果
从图 4.8 中我们可以看出，当在核函数里面使用 printf 输出结果时，一个线程束里面 64 个线程将按照

来体现程序的执行顺序。
4.6.2 使用 GPU Trap Handler
沐曦通用 GPU 架构的硬件支持将 Shader 执行期间产生的异常写进 TRAP_STATUS寄存器中，并且能
选择性地在异常发生时插入一条 trap 指令。Trap 指令会使 Shader 以更高的特权级别执行 trap kernel，
在 trap kernel 中可以定义和决定如何处理该异常，处理流程如图 4.9 所示。
图 4.9 GPU Trap Handler 处理流程
基于 trap kernel 功能，当用户层程序触发相应异常信号时，MXMACA 将进行相应处理并给出相关提示
信息以供用户进行程序代码调试。
