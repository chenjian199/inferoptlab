3.7.2.3 零拷贝内存
零拷贝系统内存与全局内存具有相同的一致性和一致性保证。核函数可以不分配或释放零拷贝内存，但
可以使用从主机程序传入的指向零拷贝的指针。
3.7.2.4 常量内存
常量是不可变的，即使在父级和子级启动之间，也不能从设备中修改。也就是说，在启动之前，必须从
主机设置所有 __constant__ 变量的值。常量内存由所有子核函数从其各自的父核函数自动继承。
从核函数线程中获取常量内存对象的地址，与所有 MXMACA 程序具有相同的语义。并且将指针从父级传
递到子级或从子级传递到父级是天然受支持的。
