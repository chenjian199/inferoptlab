3.7.8.2 API 错误和启动失败
与 MXMACA 主机端运行时一样，任何函数都可能返回错误代码，错误代码的类型为 mcError_t。
MXMACA 设备运行时暂不支持通过调用函数 mcGetLastError 检索每个线程的错误值。
与主机端启动类似，设备端启动可能因多种原因（无效参数等）而失败。但启动后没有错误并不意味着
子核函数成功完成。目前有部分情况出现错误会报 trap 进行提示。
