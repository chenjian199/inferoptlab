mcTriton 用户指南
1 概述
mcTriton 在 Triton 的基础上增加了 MXMACA® 后端，支持使用 MXMACA 硬件加速 Triton 中各类计算任
务。
当前发布包含以下版本安装包：
• Triton3.0.0 + Python 3.8/3.10/3.12，对应 torch 2.4/2.6/2.8
• Triton3.6 + Python 3.10/3.12，对应 torch 2.10
版本安装参考：软件中心
支持 x86_64/Arm 架构下 Ubuntu 20/22/24 以及 CentOS 8/9 系统上运行。mcTriton 的具体支持功能，
参见 3 功能支持。
1.1 适用产品
本文档适用于沐曦 MXC500 系列产品：曦云 ® C500、C500X、C550、C550‑PL、C588，曦思® N260，曦
索 ® X206；以及 MXC600 系列产品：曦云 ® C600，曦思 ® N300，曦索 ® X301、X302。
