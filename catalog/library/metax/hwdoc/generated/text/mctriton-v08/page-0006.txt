• Python

2.1.2 开始安装
可在 PyTorch 安装压缩包中获取 Triton 的 wheel 安装包。解压 PyTorch 安装压缩包，可以获得 Triton
和 PyTorch 的 wheel 安装包。
PyTorch 安 装 压 缩 包 以 maca‑pytorch${pytorch_version}‑py${python_version}‑
${release_version}‑${arch_info}.tar .xz格 式 命 名。Triton 和 PyTorch 的 wheel 安 装 包 分 别 以
triton‑*.whl 和 torch‑*.whl 格式命名。
操作步骤
安装方式同标准 whl 包。
1. 安装 mcPyTorch：
python -m pip install torch-\*.whl
2. 安装 mcTriton：
python -m pip install triton-\*.whl
