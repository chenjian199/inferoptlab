5.1.1 共享内存
为了进程或线程间通信，MCCL 会在 /dev/shm 中创建共享内存。因而操作系统对共享内存的限制需要
相应地增加。如果共享内存不够，MCCL 会在初始化时失败。增加共享内存大小可参考操作系统相关文
档。
Docker 容器的默认配置会限制共享内存和固页内存的大小。当在 Docker 容器中运行 MCCL 应用程序
时，需调整共享内存大小以确保程序可以成功运行。例如，在 Docker 运行时可以添加如下命令：
--shm-size=1g --ulimit memlock=-1
