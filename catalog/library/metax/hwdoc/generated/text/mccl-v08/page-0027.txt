MCCL 编程指南
4.2.1.15 MCCL_EXT_CCL_ENABLE
描述：启用混训功能。
可选值：
• 0：禁用
• 1：启用
默认值：0
4.2.1.16 MCCL_HC_PLUGIN
描述：指定异构环境使用的特定版本插件动态库。通过配置该变量，可以将沐曦 GPU 与指定其它厂商的
GPU 进行异构通信。
可选值：插件动态库路径
默认值：/opt/maca/libmxccl.so
4.2.1.17 MCCL_RINGS
描述：用户自定义环路，只在固定序号的 GPU 上进行 ring 运算。
可选值：
字符串格式为 0 1|1 0|0 1 2 3|3 2 1 0|N0 0 2 3 1|N2 7 6 5 4 3 2 1 0 N1
其中网卡可选择指定字符前缀 N 表示。PCIe P2P 可以指定字符前缀 P 表示。
默认值：无
4.2.2 性能相关
4.2.2.1 MCCL_ENABLE_FC
描述：是否启用 FC 算法。
可选值：
• 0：关闭
• 1：启用
默认值：1
