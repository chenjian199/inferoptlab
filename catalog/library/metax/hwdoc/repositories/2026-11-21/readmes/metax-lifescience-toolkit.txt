# MetaX LifeScience Toolkit

**Turn any agent into a life science expert with MetaX LifeScience Toolkit skills.**

Protein folding, molecular docking, generative chemistry, genomics analysis,
protein design, and biomarker discovery — life science libraries, tools, and
models packaged as ready-to-call agent skills for MetaX environments.

Each skill gives a coding or scientific agent structured instructions, scripts,
and references to select a tool, prepare inputs, run it, inspect outputs, and
explain results — across both single tasks and multi-step scientific workflows.

This repository includes material adapted from the
[NVIDIA BioNeMo Agent Toolkit](https://github.com/NVIDIA-BioNeMo/bionemo-agent-toolkit),
with changes for MetaX hardware and MIM service contracts. See [NOTICE](NOTICE)
for upstream attribution and a summary of modifications.

## Install
Skills install with the [`skills` CLI](https://github.com/vercel-labs/skills):

```bash
# interactive — pick a skill + install destination
npx skills add MetaX-MACA/metax-lifescience-toolkit

# one skill, no prompts
npx skills add MetaX-MACA/metax-lifescience-toolkit --skill boltz2-mim --yes

# target a specific agent (repeatable)
npx skills add MetaX-MACA/metax-lifescience-toolkit --skill boltz2-mim --agent claude-code
npx skills add MetaX-MACA/metax-lifescience-toolkit --skill boltz2-mim --agent codex

# browse the catalog without installing
npx skills add MetaX-MACA/metax-lifescience-toolkit --list
```
