**怎么看：** TPOT 为“平均 / P95”，单位 ms，越低越好；TTFT 为平均首 token 延迟，单位 s；输出吞吐单位 tokens/s，越高越好。输出吞吐按包含 Prefill 的完整请求窗口计算，TPOT 统计首 token 之后的平均间隔。
