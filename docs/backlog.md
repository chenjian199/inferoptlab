# 首版开发 Backlog

> InferOptLab · `schema_version: "0.1"`。以下 24 项可转成仓库 Issue，属于实施计划，当前均不表示已经开发完成。每项保留固定编号，便于在 PR、验收报告和里程碑中追踪。

## 使用规则

- **P0**：首条真实纵向闭环或 v0.1 发布必需；不是要求同时开工。
- **P1**：核心闭环之后的扩展。延期时必须缩小支持声明。
- **A**：控制与数据方向工程师；**B**：平台与测量方向工程师。“共同评审”不要求两人始终同时开发。
- 所有 GPU 功能的完成条件都要有真机证据。mock 可用于契约、调度和失败注入测试，不能替代性能验证。
- 下表依赖指最低依赖；实施中可更早开发接口与测试样例，正式验收仍需等依赖完成。
